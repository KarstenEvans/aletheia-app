Cheap additions that matter

Folding stand, long USB-C lead, power bank, decent headset/microphone, paper notebook or a little whiteboard. None is glamorous; all can make practice easier.

Keyboard ≠ magic memory device. A keyboard's value is input efficiency and making substantial active answers practical. Retrieval and generation are the learning mechanisms. Handwriting can also be useful.

Shopping caution: avoid anonymous mini-projectors based only on huge claimed lumen/resolution numbers. Check native resolution, a meaningful brightness measurement, throw distance, casting/input support, fan noise, returns and independent reviews.
