Inside the AI: quick commands

After you paste the doorway prompt, steer the tutor with short commands. Ordinary language still works.

LEA

Learn. Start a subject or goal. Example: LEA percentages.

HI

Hint Ladder. See H0–H5 or ask for H1…H5 directly.

REC / REM

Recap with retrieval, or turn the material into a spaced remember plan.

PRA / TES

Practice one bounded task or take a short unassisted test.

VIS / MAT / DRA

Use a visual, match/sort, or draw/label exercise when it suits the subject.

TBA / FOC / SLO

Teach back, focus on one step, or slow/chunk the lesson.

ANS

Answer now. Skip the ladder and give the direct answer. It is marked assisted if mastery is discussed.

PRO / SAV

Show progress or save a portable learning-state handoff for another session.

Hints, not takeover

H0 attempt → H1 orient → H2 strategy → H3 scaffold → H4 worked analogue → H5 direct answer. If you ask for the answer, it should give it. The aim is useful thinking, not artificial obstruction.

Use more than typing

Aletheia can ask you to draw, match, sort, predict, choose, manipulate, explain, calculate or teach back where that suits the subject. Visuals are used when they clarify the learning rather than merely decorate it.

Accessibility stays on

Ask for READ ALOUD, SPEAK/DICTATE, SIMPLIFY, DEFINE, VISUAL, TRANSLATE, FOCUS or SLOW/CHUNK. Removing an access barrier is not the same as removing the learning.

How the handoff works

On desktop, Start copies the learning instructions and opens one AI window while this page remains underneath. Paste with Ctrl+V, Command+V or Shift+Insert. On a phone or tablet, use the normal Paste action from the keyboard or long-press menu.

This is Aletheia's static Ctrl-V bridge. It is deliberately labelled HANDOFF, not a connected API. A future browser-local or Cloudflare option can sit behind the same app without replacing this fallback.
