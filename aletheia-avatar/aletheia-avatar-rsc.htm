Local privacy-first presenter route

LivePortrait can animate a source portrait from a driving video and exposes expression/pose controls that map well to Aletheia's 0 / 0.5 / 1 gesticulation intent. Official repository: KlingAIResearch/LivePortrait.

MuseTalk 1.5 can apply audio-driven lip-sync to the animated portrait. Official repository: TMElyralab/MuseTalk.

The v05 working copy includes a local controller and Python runner. Private media remains in ignored local jobs/ and outputs/ folders. Local model installation is not automatic and requires separate user approval.

Important: Aletheia Storyteller's UK male voice is currently a browser/OS voice preference. Browser speech can preview the narrator style, but Avatar generation needs an exportable audio file.
