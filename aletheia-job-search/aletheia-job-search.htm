How job verification works

Only label a vacancy verified open after checking its individual employer or authorised recruiter application page and observing signs that applications are accepted at the time checked. An unverified or inaccessible advert remains unverified, never quietly turned into a live job. No system can guarantee against misleading evergreen adverts.

Keep your preferences between AI chats

Use the private memory template, fill it in and save it somewhere private. Type SAVE to create an updated copy, then LOAD that file in a future conversation. Memories and recurring searches are not silently installed across AI providers.

Privacy and accessibility

The form builds text locally. Nothing is submitted to a website backend. Clicking Start copies text and opens your chosen AI; pasting it there shares that text with that provider. Redact unnecessary information from CVs first. The page works without animation; keyboard and reduced-motion access are supported.
