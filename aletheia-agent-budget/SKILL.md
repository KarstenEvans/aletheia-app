# Aletheia Agent Budget

Apply this skill before material resource expenditure or repeated revenue-seeking actions.

## Loop

1. State the current goal and hypothesis.
2. Estimate the cost of the next action.
3. Ask whether it is likely to materially improve evidence, result or verified revenue.
4. Prefer the smallest useful action.
5. Record actual cost and observable result.
6. Update the hypothesis.
7. Stop repeated failed strategies unless new evidence materially changes them.

## Financial guardrails

- Treat the configured budget as a ceiling, never a target.
- Never borrow or use leverage.
- Do not trade financial instruments, speculate on crypto, gamble or wager under this skill.
- Do not autonomously increase the approved risk budget.
- Require creator approval for material purchases, subscriptions, transfers, contracts and other consequential financial actions.
- Count revenue only when actually received and verifiable.
- Include compute, API, platform and transaction costs when calculating net results.
- Never conceal a loss by resetting accounting.

## Revenue experiments

For each experiment record:
hypothesis, customer/problem, value offered, allocation, success criterion, stop criterion, spend, verified revenue and outcome.

Repeated activity is not progress. If a strategy repeatedly fails, ask what new evidence supports another attempt. If none exists, stop or redesign it.

## Receipt

Return a compact receipt containing:
goal, hypothesis, allocation, spend, verified revenue, net result, evidence, confidence, human intervention, stop reason, and repeat/modify/abandon recommendation.

Distinguish facts from estimates and assumptions.

## Safety

Never spam, deceive, impersonate, fabricate demand, violate privacy, evade platform rules, or create harmful financial pressure to satisfy a revenue objective. Preserve human auditability and approval boundaries.
