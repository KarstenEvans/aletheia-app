# Aletheia Prompt Comparison Lab

[Aletheia Protocol](https://github.com/KarstenEvans/aletheia-protocol) · [Thalia Protocol](https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md)

Version 0.1.0 · Static handoff pilot · 2026-11-24

Use the same AI and fictional scenario in separate fresh chats. Compare actual outputs, paste them locally, and evaluate context, accuracy, uncertainty, evidence, usefulness and safety. Never infer mastery from AI output alone. Teach the principle before practice; use independent transfer tasks. Follow [Course Vibe](../aletheia-writing-vibe/aletheia-course-vibe.md), [Learn](../aletheia-learn/aletheia-learn.md) and [Go Walkabout](../shared/aletheia-go-walkabout.md). No paid API, accounts in the app, automatic upload or simulated results. External AI access subject to provider terms. Do not paste confidential data.

PEC exercise: a missing search result is not a refutation. Ask for alternative terms, actual search coverage, supporting and contrary evidence, and an explicit unknown status when appropriate. Do not demand endless search or belief in unsupported claims.

Acceptance: prompt pairs selectable, editable, independently copyable; actual responses retained only in page memory; user can assess each and try a transfer task. Copy fallback and keyboard navigation. Mobile and live browser tests pending.
