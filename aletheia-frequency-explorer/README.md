# Aletheia Frequency Explorer

A static Aletheia browser app for experimental binaural audio, generated music, optional story songs and narrated short stories.

Open `aletheia-frequency-explorer.htm`.

## Quick default

The initial pair is **300 Hz / 303 Hz**. The 3 Hz difference is labelled delta-range for orientation only; it is not claimed as an ideal or therapeutic frequency.

Open **☰** to change frequencies, duration, music, voice and narration behaviour.

## Story library

The app reads `stories/stories.json`. It includes the supplied Ike and Rocket/Flurkin texts plus two new original Aletheia narrations about Schrödinger and Newt/Tiff.

## Optional audio

Expected paths:
- `audio/Ike-Sour-Tea.mp3`
- `audio/Ike-Sour-Tea-02.mp3`
- `audio/Ike-the-Shield-Bug.mp3`

The app also supports selecting a local audio file, so missing hosted audio does not block use.

## Safety

Start quietly. Stop for pain, ringing, pressure, dizziness or discomfort. Browser volume is not calibrated dB SPL. This is not a medical treatment.

See `aletheia-frequency-explorer-rsc.htm` for research links and caveats.
