ⓘ What do the beat frequencies mean?

The difference between the two ear tones is the binaural-beat frequency. Conventional EEG bands are often labelled roughly delta 1–4 Hz, theta 4–8 Hz, alpha 8–13 Hz and beta 13–30 Hz. Matching a difference to a band does not prove the brain will be forced into that state or create a particular effect.

6. HELP

THIS .HTM FILE IS THE COMPLETE APP. BINAURAL EXAMPLE DEFAULT EXAMPLE: LEFT 300 Hz + RIGHT 303 Hz = 3 Hz difference. This is a delta-range preset, not a proven ideal or treatment setting. SWAP EARS Press ⇄ Swap ears. The actual left/right oscillator assignments are exchanged. SPEECH Every visible non-empty reflection line is a separate utterance. After a line finishes, the app waits the chosen Pause value. ONCE = stop after the last line. LOOP = return to the first line and repeat until the sound session ends. VOICE Preferred default: Catherine · English (Australia), when available. If Catherine is unavailable, the app prefers another en-AU voice, then falls back to the browser default. You can still choose any other voice exposed by this browser/device. Preview Voice reads one short test sentence. SPEECH VOLUME Adjust speech independently from binaural tone and music. Default is 85% of the browser speech-synthesis maximum. If words are difficult to hear, raise Speech Volume and/or lower Music Volume. Browser/device master volume still applies. LOCAL SPEECH TEXT Choose a .txt or .md file from your device. Split it by sentences, line breaks, or paragraphs. “Use selected text for speech” replaces the current reflection display with that imported text. “Restore generated reflection” returns to the last generated reflection. The local file is read only in this browser session. FRESH REFLECTION “Find inspiration” searches Wikisource for public historical material related to the selected palette. A short source seed is used to choose a theme. New wording is created locally and is NOT attributed as a historical quotation. THALIA WARM Uses stronger absurdist, dry, semantic and occasionally cosmic/bureaucratic humour mechanisms. It does not copy Monty Python, Red Dwarf, or another creator's actual lines/style. MUSIC Built-in music is generated by this file. The binaural tone and music have separate volume controls. A licensed local recording can be used instead. AI Upload this same .htm file to a capable AI. If that AI cannot execute browser audio, it must not pretend it is playing.
