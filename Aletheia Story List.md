## Command: LET'S DO A STORY
On receiving **"Let's do a story"** (also "next story", "do the next one"):
1. FETCH the **current GitHub main** version of this file; do not rely on an earlier chat or stale copy.
2. Select the lowest-numbered story NOT marked **COMPLETE**. Default first item is **S001**; on future runs advance only when the current one meets the completion gate. If user names a number, use that number.
3. Run **Aletheia Improve** on that exact story: inspect registry, Storyteller `stories.json`, existing story Markdown, visual assets, knowledge index, shared GUI/dev and page/resource specs; prevent duplicates and overwrites.
4. Return the existing material before changing it. Retain Copilot / Kes / Sif attribution. No use of Copilot's later story in a distinct parallel-story branch.
5. Create/reconcile: (a) canonical story Markdown; (b) story map and scene cue map; (c) low-intensity/normal reading options as appropriate; (d) original images or asset manifest; (e) HTM browser Storyteller/page spec with star navigation if applicable; (f) resources/books/gifts page or justified shared resources route; (g) original YouTube narration, visual storyboard, scene timing and description prompt (not a published video); (h) factual knowledge research notes with sources **only where applicable**; (i) source/rights/attribution notes; (j) testing receipt and backlinks/index proposal.
6. Use approved shared GUIs/dev rules. Existing rules are not assumed to have been fully adopted: changes to global GUI/dev contracts require separate review. Do not duplicate content into Swindon.org.uk; link complementary front doors if useful.
7. Finish only after review + appropriate tests; mark precisely WRITTEN, SPEC_READY, ASSETS_READY, HTML_READY, INDEXED, LIVE_TESTED, COMPLETE. If artwork or public browser verification is missing, preserve partial status and continue **same** item next time.
8. Save current state and next action here, plus app tasks/ideas as appropriate. No autonomous publication to YouTube or LinkedIn. No invented finished work.

## Safety / quality
Stories involving memory are fiction, not a representation of neurological dementia or AI subjective distress. Low-intensity controls are user-selectable and not a claim of ADHD therapy. If user-owned or contributed images are not available, list artwork as missing, never invent installed binaries. Crosslink without claiming live deployment or finished video.
