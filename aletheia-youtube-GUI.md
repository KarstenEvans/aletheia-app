## Interface
- Result first: select a completed story source; preview six scene cards with assigned image, zoom/pan/hold, voice and captions.
- Controls: Source story, Preview, Generate video-script Markdown, Export caption plan, Verify assets, Review, Approve handoff. **No imaginary Render/Publish button** if no capable backend installed.
- Responsive, keyboard/screen-reader labelled controls, reduced motion, clear video-status labels.
- Storyteller remains the cinematic renderer; YouTube GUI is a production handoff/readable script, not a duplicate Storyteller.
- Resources and Books & Gifts link via actual story resources; affiliate disclosures and human approval remain separate.
- If implemented as HTML, obey current shared GUI/dev, existing Constellation catalogue, and supply specific page.md, resources and real button wiring.
- A draft may be exported without images; label assets missing and block READY / PUBLISHED.
- Human approval before account upload, metadata modification, external API action.
