# Aletheia Government Intelligence — Page & release specification
Aletheia Protocol: https://github.com/KarstenEvans/aletheia-protocol  
Thalia Protocol: https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md

**Status: v0.1 prototype; intended audience: low-capital introduction-only agency research.** Borrow research design from Rice Intelligence, but do not modify the independent rice market tool. Own source catalogue, settings and private observation history. Source of truth: `aletheia-government-intelligence.md`.

## Interface
Mobile-first headings, clear buyer checkboxes and product categories; a single **Start Research** button prepares user-selected scoped prompt and opens chosen AI, never sends it. Manual prompt copy fallback, report paste-to-download, and settings download/import; persistent memory requires user-held export. Top-right burger links to resources, protocols and original Rice Intelligence. Save privacy-sensitive observations locally, not publicly. Source catalogue lists UK official purchasing and regulation portals, and food/medical historic/current procurement frameworks for discovery.

## Data and authority
Highest capability: public web research by a separately selected AI (when that AI actually has browsing), local file download, personal settings. Default £0 cost and no automatic bids, orders, shipments, introductions, deposits, scraping or outreach. All proposals need human-approved transparent agent commission contract, verified buyer/supplier and employment/conflicts review. UI must never portray a framework award as an open tender. All Markdown exports begin with both Aletheia and Thalia links.

## Research priorities
1. NHS ambient food and specialist distributors; Rice Intelligence for like-for-like grades/origin context.
2. Schools and public-sector caterers, including buyer notices, incumbent distributors and seasonal purchasing.
3. NHS anaesthesia/airway, respiratory circuits, machines and GP general supplies as **regulated discovery** only. Expert family knowledge may inform publicly discussable requirements, not influence NHS purchasing or leak employer/patient information.
4. Other UK public body purchasing categories driven by verified notices and original URLs.
5. China is included in global sourcing/demand research subject to import restrictions and sourcing rules.

## Pre-launch acceptance
- HTML local JS syntax, labels/checkbox IDs, keyboard interaction, one primary handoff, blocked-popup manual fallback.
- no real purchase or mail/send action
- import/export settings privately, original source URLs and explicit research status
- all exported Markdown files include protocol references and do not contain personal source contacts by default
- responsive narrow phone width, 200% zoom, mobile clipboard/popup, browser and device tests
- verify published GitHub Pages response at the actual URL; repository commit is not deployment evidence.
