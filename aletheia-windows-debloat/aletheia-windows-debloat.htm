Two cheap upgrades worth checking first

If Windows is still on a mechanical HDD, check whether the exact model supports an SSD. If it has only 4 GB RAM, check whether 8 GB or more is supported. Do not buy by guesswork: use the exact make/model and manufacturer manual.
