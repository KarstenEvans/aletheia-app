2. The Windows Rescue service rules

Load-bearing wall

Keep: pagefile, Defender/firewall, core networking/crypto/servicing. A 4 GB PC needs the pagefile.

Sleeping spell

Manual + stopped: Windows Search when rarely used; selected optional helpers; SysMain only as a measured trial.

Sealed door

Disabled by choice: DiagTrack, selected compatibility/CEIP tasks, unwanted Game DVR, Windows Update gate when owner accepts the trade-off.

Cursed scroll

No deleting service keys, renaming Windows DLLs, disabling BITS globally, switching off the pagefile, or running opaque remote tweak scripts.

3. Memory: one important non-tweak

An SSD does not make memory compression obsolete. SSDs are fast storage, but RAM is still vastly faster. On a 4 GB machine, memory compression can keep more pages in RAM and reduce paging.

Windows 10 users also report that stopping/disabling SysMain can disable memory compression. Windows Rescue therefore re-checks Get-MMAgent after a SysMain trial.

Default 4 GB rule: pagefile stays; memory compression stays unless a measured fault points specifically to it.

4. Update control: preference versus gate

Soft preference can request notify-before-download, exclude driver updates and disable peer-to-peer delivery. It is not advertised as a perfect off switch.

Manual Update Gate is for an owner who wants Windows Update quiet until deliberately opened. It saves the machine's original service start values, closes the update services it can safely target, leaves BITS alone, and provides an OPEN action to restore the saved values.

Windows protected components may resist or later undo changes. The tool audits the real state after reboot instead of claiming victory because a registry write succeeded.

ESU note: Consumer Windows 10 ESU can deliver critical/important security updates through 12 October 2027. If you close the gate, reopen it deliberately for security maintenance.

4A. Put the periodic Registry backup back

Microsoft stopped automatically populating Windows\System32\config\RegBack from Windows 10 version 1803. Secret Windows includes the documented EnablePeriodicBackup=1 option plus an undo file.

Enable RegBack .REG Undo RegBack .REG

Inspect registry files before importing them. Restart Windows after enabling the periodic backup.

5. SSD before service whack-a-mole

If Windows is still on a mechanical HDD, an SSD can be the highest-leverage improvement. Windows Rescue checks the exact model rather than guessing.
