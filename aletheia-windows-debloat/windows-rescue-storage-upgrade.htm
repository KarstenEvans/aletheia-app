Windows Rescue: SSD / M.2 / mSATA / Optical-Bay Guide

Rule zero: identify the exact PC model and OEM service manual before buying a drive or caddy.

Small slot ≠ NVMe

Possible storage includes 2.5-inch SATA, mSATA, M.2 SATA and M.2 PCIe/NVMe. M.2 describes the card shape; it does not tell you whether the interface is SATA or NVMe.

A WWAN/WLAN slot can look inviting and still be unsuitable for storage. SD-card boot is deliberately outside the normal Windows Rescue path unless the manufacturer documents it.

Example: Dell Latitude E7240

Dell documents the E7240's SSD as mSATA. That is precisely why Windows Rescue refuses to infer “M.2” from a small card or a laptop's year.

Dell E7240 manual

Best-case old-laptop layout

If the OEM documents an unused boot-capable SSD slot:

  • SSD → Windows, applications and pagefile (C:)
  • existing healthy HDD → personal data (D:)
  • DVD drive stays in place

Clone or clean-install Windows onto the SSD, test several boots, and do not erase the old disk immediately.

Classic 2.5-inch HDD + DVD route

If there is no extra SSD slot:

  1. Replace the primary 2.5-inch HDD with a compatible SATA SSD.
  2. Confirm whether the optical bay is SATA or PATA.
  3. Measure/check the service manual for 9.5 mm or 12.7 mm caddy size.
  4. If suitable, install the old HDD in the optical caddy as D: data.

Cheap caddies exist, but buying the wrong £5 caddy is still buying a £5 metal bookmark.

Before cloning or changing boot

  • Back up important data elsewhere.
  • Verify access to any BitLocker/device-encryption recovery key. Do not paste it into AI.
  • Confirm UEFI/Legacy and GPT/MBR state.
  • Use the OEM manual for drive removal and boot instructions.
  • Keep the old drive untouched until the SSD has booted and worked reliably.

Clone or clean install?

Clone: quickest way to preserve programs/settings.

Clean install: often better when the old Windows installation contains years of unwanted startup software and update debris.

Rufus is a useful open-source installation-media tool. Inspect its options before using them.

Do not move the whole Users tree

Keep Windows/apps/pagefile on the SSD. Move Documents, Pictures, Videos, Downloads and other personal data to D: using normal folder-location/storage settings if desired.

The old HDD is not a backup. Old drives fail. Keep a second copy of anything irreplaceable.

Upgrade versus replacement

Price the exact compatible SSD/RAM/caddy, then compare that total against a current new or certified-refurbished laptop.

Research-date example: on 30 August 2026 Currys listed an HP Ryzen 3 / 8 GB / 256 GB SSD laptop for £299. Recheck before buying.
