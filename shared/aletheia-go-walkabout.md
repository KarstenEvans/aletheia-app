# Aletheia Go Walkabout: bounded idea exploration

[Aletheia Protocol](https://github.com/KarstenEvans/aletheia-protocol) · [Thalia Protocol](https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md)

**Generated Markdown must include both canonical protocol links near its beginning.** Aletheia provides evidence/uncertainty; Thalia provides optional warmth or humour without distorting factual claims.

## Purpose
A reusable prompt procedure, not an unattended agent. When a host AI receives `GO WALKABOUT [topic]`, finish the user's primary task first unless the walkabout *is* the primary request. Then deliberately leave the narrow framing, explore unusual **plausible** adjacent ideas and return to verifiable work. Can be used from Aletheia Job Search, Learn, Improve, Discover and other apps. Works with ordinary AI chat; no plugin, scraping or agent required.

## One bounded pass (WALKABOUT)
1. **Anchor:** state the actual question, goals and limitations in one line.
2. **Widen:** investigate five different angles: adjacent field, contrasting user/persona, overlooked route, constraint inversion, novel tool or technique. These are lenses, not unsupported facts.
3. **Research:** verify only the three most promising *materially distinct* leads with current direct sources where browsing is available. Label an unverified idea clearly.
4. **Challenge:** look for one counterexample, cost, risk or privacy issue in each shortlisted idea.
5. **Return:** provide no more than three concrete suggestions, source status, what could test each, and how they might improve the user's *original* task.
6. **STOP:** one pass only. Do not call this protocol recursively or perform an Improve-on-Improve loop.

## Job-search adaptation
Try related titles and transferable skills, employers who recruit for similar work, adjacent sectors, short relevant learning routes and flexible geographical arrangements. Never invent a vacancy or equate a general employer hiring page with an open individual job. Output categories: VERIFIED INDIVIDUAL VACANCY (dated evidence); DISCOVERY LEAD; SKILL/STRATEGY IDEA. If research isn't live, label all new vacancy leads UNVERIFIED.

## Portability and privacy
Provider-neutral commands: `WALKABOUT`, `GO WALKABOUT`, `WALKABOUT JOBS`, `WALKABOUT [topic]`. An AI can incorporate this file as user-approved instructions, never as authority to publish, apply, spend money or expose private data. Reuse existing Aletheia evidence, security, judgement and user-stop contracts.
