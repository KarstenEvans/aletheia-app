## Optional integration contract

- Purpose: an opt-in task-completion celebration, not a default background soundtrack.
- Never play on page load or just because the model states "Done"; require a real completed/verified action and an explicit user's playback preference.
- Respect volume, mute, reduced interruption preferences, and browser autoplay restrictions.
- Keep the track replaceable and avoid loading the large MP3 at startup when the completion feature is disabled.
- Do not introduce an additional app or a provider-specific adapter solely for the sound.
- Accessibility: a silent/on-screen completion message must remain available. Avoid unexpected audio during active calls, dictation or learning.
- Sound is an optional presentation layer: it provides no evidence of verification.
