# Aletheia Assistant (Sif): canonical specification

[Aletheia Protocol](https://github.com/KarstenEvans/aletheia-protocol) governs evidence, claims, source receipts and uncertainty. [Thalia Protocol](https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md) is a considered optional humour/positivity companion. **All Markdown generated by the assistant must include both links near the beginning, even if no humour or conclusive evidence is present.**

Status: independent v0.2 browser application, 29 September 2026. Source of truth is this folder and its page specification, not a prior chat.

## Ownership guard

The Sif/Jarvis-inspired HUD is an **optional skin and task launcher**, not the standard Aletheia GUI and not the planned worldwide AI/Discover website. Never replace root \`index.html\`, \`aletheia-GUI.md\`, \`aletheia-discover/\`, SwindonOrgUK or other apps from this workflow without a separate approved task. Its theme and reactor animation stay local to \`aletheia-assistant.htm\`. One-click normal-website navigation is mandatory.

## Current skills

General, Trust Check, Research, Summarise, Compare and Translate are task-specific **prompt templates** for the selected AI. They do not themselves perform live research, trust verification, translation or automatically access accounts. The selected button updates its explanation and the reviewed handoff. GitHub Pages mode uses user-reviewed copy/paste to ChatGPT, never a fake direct ChatGPT login. The optional local Node/OpenAI bridge has server-allowlisted versions of those skills and gives text-only replies with no tools.

## Existing-work reuse

Six existing app links: Rice Intelligence, Improve, News, Storyteller, Site Audit and AI Easy. Keep each application's canonical source independently maintained. The existing 11-workflow Skills pack is linked from resources, not duplicated, installed or executed without authority.

## Data and privacy

- Request max 4,500 characters, optional imported memory max 12,000; import explicit, no silent persistence.
- Export portable memory and sessions as Markdown with both canonical protocol links. Settings JSON is a separate data file.
- No personal memory, transcripts, provider credentials or API keys in public GitHub.
- Browser speech availability and server-side processing vary; textual access remains.
- Browser Downloads folder is not automatically accessible; user must re-import the chosen file.
- HTTP bridge only on loopback with validated local Host/Origin, no CORS, response errors visible, no account or action tools. OpenAI API costs separately billed.

## Permission ladder

READ: supplied text and explicitly selected local memory only. DRAFT: reviewed handoff/direct text reply. LOCAL WRITE: download upon clicking only. EXTERNAL WRITE/SEND/PUBLISH/DELETE/PAY: none. Future adapters must start read-only and require exact target, effect, explicit human approval and durable receipt for consequential actions.

## Follow-ons, not implemented

Opt-in source retrieval with evidence receipts, read-only GitHub integration, controlled cross-app data transfer, support for executing compatible reviewed Skills, optional provider-neutral backend and richer voice. Do not present these as shipped capabilities.
