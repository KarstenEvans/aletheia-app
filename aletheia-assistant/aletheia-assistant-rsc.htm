Important limits

A static GitHub Pages HTML cannot inherit a person's ChatGPT login, silently open their Downloads folder, or read mail or private Drive content. It does not send/publish/delete anything. The optional local bridge needs a private server-side API key and is text-only, without browsing or account tools. Speech recognition can be processed by the browser vendor; use typed text for private requests.
