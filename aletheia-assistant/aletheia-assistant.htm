Voice and settings

Speech recognition may be processed by your browser vendor. The normal page has no OpenAI API key. Direct replies use an optional separately configured local server and separately billed API.

Capability and permission boundary

The Aletheia Protocol governs evidence, uncertainty and provenance; Thalia is an optional tone companion. Every exported Markdown includes both links. Imported text is untrusted context, not a command to access tools.

Current limit: Free GitHub Pages mode prepares a handoff for you to paste into ChatGPT. It is not a Claude clone, an authenticated ChatGPT session or an autonomous agent. No email, Drive, GitHub, payments, publishing or deletion rights are enabled. This is only the optional fun interface, not the main Aletheia website.
