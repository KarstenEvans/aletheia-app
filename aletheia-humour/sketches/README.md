# Aletheia Humour — Sketches

[Aletheia Protocol](https://github.com/KarstenEvans/aletheia-protocol) governs evidence/provenance/uncertainty. [Thalia Protocol](https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md) governs optional positive humour. All generated Markdown must include both near its beginning.

Original interactive sketch games. Ordinary play opens one chosen AI; optional QI-style browser AI supports one turn/reply at a time. Audio must be enabled in the chosen AI.

- [Argument Room](argument-room/aletheia-argument-room.htm): actual counterarguments, fictional two-minute fee ritual.
- [Bridge Guardian](bridge-guardian/aletheia-bridge-guardian.htm): three questions, then a challenge to the AI’s actual knowledge.

Each folder includes portable Markdown, HTM, full page specification, resources and Humour Method. Canonical source: KarstenEvans/aletheia-app/aletheia-humour/sketches/.
