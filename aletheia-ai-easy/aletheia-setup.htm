Before you start

This page is designed to run locally in your browser. It does not need a server and this version sends no form data anywhere.

You choose what goes in the file. Use a town/city/region rather than an exact address unless you have a specific reason. Never put passwords, one-time codes, API keys or recovery keys here.

🤖 ChatGPT Free: quick setup (optional)

Aletheia AI Easy works with any supported AI. If you use ChatGPT Free, these three steps save you repeatedly explaining how you want it to work.

Show the three ChatGPT Free steps and copyable profile
  1. Set your privacy: Open Settings > Data controls and review Improve the model for everyone. Check Memory separately in Settings > Personalization. Neither setting deletes old chats.
  2. Set your short profile: Open Settings > Personalization (on mobile, Customize ChatGPT), enable customization, then copy and edit these simple rules. Free Custom Instructions currently allow 1,500 characters.
  3. Keep longer context in a Project: Create a free Project called Aletheia, paste the full bootstrap into Project instructions, choose the Project's Memory option deliberately and optionally add the personal memory file generated below. Free Projects currently allow five files each. Project instructions override global Custom Instructions.

Speaking tip: For research or tables, try Dictation into the normal text box so you can correct the transcript before sending. Live Voice can search and use memory, but a written response is easier to check. Use Read Aloud afterwards when available.

Before sharing: Shared Projects reveal their included chats, files and instructions to collaborators. Keep private memory separate or check permissions carefully.

Where should I save it?

Recommended permanent home: an Aletheia folder under Documents, or an Aletheia folder in your phone/tablet Files app. Downloads is fine as a temporary landing place but is not ideal as the long-term source of truth.

Can this page save straight into Documents?

Browsers deliberately restrict silent file access. Where supported, the Save button opens a file picker so you choose the location. Otherwise it downloads the file and you can move it yourself.
