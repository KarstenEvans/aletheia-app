# Aletheia AI Easy - Five Short Setup Videos

These are **not a five-day course**. They are five short optional setup videos, generated using Aletheia Avatar and text-to-speech where practical. A user who prefers text should be able to complete the same setup without watching any video.

## Character direction

Use an original Aletheia guide character: a friendly, slightly eccentric digital professor/bobblehead with a warm scientific feel. Avoid making it a direct copy of Albert Einstein. The character can have expressive eyebrows, energetic hair and a small Aletheia/octopus motif, but should have its own face and identity.

## Video 1 - What do you want AI to help you with?

**Target:** 60-90 seconds.

Purpose: replace the intimidating question "Which AI system do I need?" with "What would you like help doing?"

Show examples: local search, finding work, checking a claim, comparing prices, writing, learning, planning, fixing a computer, creating a website.

End: "You choose. Aletheia only loads what you ask for."

## Video 2 - Make your portable Aletheia Memory

**Target:** 2-3 minutes.

Open `aletheia-setup.htm`. Explain that every question is optional. Demonstrate a coarse location, preferred name, regular searches, response/humour preference and selected apps. Generate `aletheia-memory.md` and save it into the user's own `Aletheia` folder.

End: "This file belongs to you. You can open it, edit it, move it or delete it."

## Video 3 - Put Aletheia into the AI you already use

**Target:** 3-4 minutes.

Use short branches for ChatGPT, Gemini, Claude, Copilot and DeepSeek. The visual should emphasise the common pattern: instructions/bootstrap + optional memory, while showing that each provider has different buttons and persistence.

End: "One Aletheia idea, several adapters."

## Video 4 - Choose only the Aletheia apps you want

**Target:** 2 minutes.

Show `APPS`. Demonstrate selecting Aletheia Search/Trust and Local A2Z while leaving other apps unselected. Explain that app suggestions are allowed but activation requires the user's choice or clear request.

End: "No surprise tentacles."

## Video 5 - Save it, move it, hand it to another AI

**Target:** 2-3 minutes.

Show `SAVE MEMORY`, `CHECKPOINT` and `HANDOVER`. Move the memory/handover file from one provider to another. Explain that provider memory is helpful but the portable file is inspectable and user-controlled.

End: "Your useful context should travel with you, not trap you in one AI."

## Production tasks

- [ ] Add scripts/voice text for each video after the setup flow is stable.
- [ ] Generate character art with an original Aletheia identity.
- [ ] Use Aletheia Avatar as the first production test.
- [ ] Prefer free/local TTS/avatar engines where quality is adequate.
- [ ] Add captions and a text transcript for accessibility.
- [ ] Keep every video replaceable as provider UIs change.
- [ ] Do not show passwords, private account details or real personal memory files in demos.
