# Aletheia AI Easy

Step 1: **Aletheia AI Easy helps you set up your chosen AI.** Choose optional preferences, build a private portable memory file and learn how to use ChatGPT, Gemini, Claude, DeepSeek or another supported AI. This is not a course or an assistant.

Step 2 (optional): **[Aletheia Assistant (Sif)](../aletheia-assistant/aletheia-assistant.htm) helps you use your AI.** It is a friendly task/voice interface for asking questions and opening Aletheia apps, not another setup system.

## Files

- `aletheia-bootstrap.md` - vendor-neutral loader/rules.
- `aletheia-memory-template.md` - blank portable user memory.
- `aletheia-setup.htm` - local consent-first memory builder.
- `provider-installation.md` - current setup routes for ChatGPT, Gemini, Claude, Copilot, DeepSeek, Kimi, Manus, Grok and optional Odysseus orchestration.
- `five-video-setup-series.md` - scripts/plan for five short setup videos, not a five-day course.
- `course-ideas.md` - genuine learning/course candidates.
- `user-guide.md` - beginner documentation.

## Design rule

The bootstrap points to apps; it does not swallow them.

Aletheia AI Easy must remain usable without a paid API, server, database or subscription. Provider-specific conveniences are adapters, never mandatory dependencies.
