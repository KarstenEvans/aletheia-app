# Aletheia Learning - Course and Guide Ideas

## First distinction

**Aletheia AI Easy setup is not a course.** It is a short onboarding/install guide with five optional videos.

The existing **Aletheia AI Starter** is already the natural beginner introduction to AI. Do not duplicate it simply to manufacture more "courses".

Build a course only when a topic benefits from practice, examples, exercises or a meaningful finished output.

## Strong candidates

1. **Aletheia AI Starter - AI without the fog**  
   Existing direction. Ask better questions, try voice/image/files/web, spot uncertainty and understand what an AI can and cannot actually remember.

2. **Search, Sources and Trust Check**  
   Finish with a repeatable research habit: find sources, distinguish claims from evidence, check freshness and compare conflicting results.

3. **Portable Memory and Handover**  
   Build an inspectable project memory, checkpoint and handover that survives a move between AI systems.

4. **Local AI - Build Your Own A2Z**  
   Choose a town/region, search local services/events, use maps where available, verify listings and build a lightweight local directory without a database.

5. **AI for Job Search and Employment**  
   Build a portable employment profile, search only live vacancies, tailor CV/application evidence and track applications without surrendering the data to a paid platform.

6. **Build a Simple Website with AI**  
   Markdown-first specification -> static HTML -> free hosting -> SSL/DNS -> accessibility -> site audit. Swindon.org.uk can be the reference case without making Swindon a requirement.

7. **Storytelling and Content with AI**  
   Find a message, turn real experience into useful stories, plan formats, create/edit video and measure what actually works. Link to good external public material, including selected Creator College/Jun Yuh videos where genuinely relevant. Do not copy their paid course material.

8. **AI for a Local Business**  
   Website copy, FAQs, bookings, local search, reviews, content, customer messages and simple automation, with Royal Orchid Thai Massage as a possible worked example after owner approval.

9. **Privacy, Digital Footprint and Aletheia 007**  
   Find what is public, verify identity carefully, reduce exposure, understand consent and create lawful removal/request workflows.

10. **Free Automation without a Server Bill**  
    Static HTML, GitHub, Cloudflare, Google/Microsoft storage, local browser code and opt-in AI automations. Explain when a paid API/server genuinely becomes necessary.

11. **Create Your Own Portable Aletheia App**  
    Start with one problem, write the Markdown contract, add optional static GUI, create a test, provenance and handover, and publish on GitHub Pages.

12. **Home Energy - Solar, Batteries and Tariffs**  
    Future guide/app covering solar PV, home batteries, smart tariffs, heat pumps/EV charging where relevant, grants/eligibility, quote comparison, payback assumptions and source checks. Commercial/referral links remain clearly disclosed on resource pages rather than shaping the analysis.

## External-resource rule

Aletheia learning material should not recreate a good public tutorial merely to keep people on our site. When a trustworthy creator has already explained something well:

- link to the specific public page/video;
- credit the creator and platform;
- say why it is useful;
- optionally embed the official YouTube player when embedding is enabled;
- provide our own short Aletheia context/checklist around it;
- keep a fallback explanation if the external link disappears;
- never copy/rehost paid lessons, downloads, slides or protected videos without permission.
