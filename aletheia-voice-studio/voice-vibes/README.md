# Aletheia VoiceVibe Library

[Aletheia Protocol](https://github.com/KarstenEvans/aletheia-protocol) | [Thalia Protocol](https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md)

Four original voice research profiles; only descriptive Markdown and transcript drafts are public in this release. The full local ZIP includes separate user-supplied synthetic WAV and historical research PDFs. A static site cannot enumerate GitHub subfolders automatically: `voices.json` explicitly lists each profile. Do not interpret the historical labels as a licence to impersonate their subjects.

**Other apps:** [Mini-AI-Me](../../Mini-AI-Me/index.htm), [Writing Vibe](../../aletheia-writing-vibe/aletheia-writing-vibe.htm), [Humour](../../aletheia-humour/sketches/index.htm), [Avatar](../../aletheia-avatar/aletheia-avatar.htm), [Storyteller](../../aletheia-storyteller.htm). These remain canonical; this folder does not copy their engines.

**New research profile:** [Maxi Jazz VoiceVibe: Experienced Soul](Maxi%20Jazz%20VoiceVibe/Maxi%20Jazz%20VoiceVibe.md), a description for a distinctly original mature spoken-word voice; no commercial recordings, no imitation or WAV yet. [Faithless HitsVibe](../../aletheia-hits/hits/faithless-hits-vibe.md) separately covers composition.
