Create your own three-file VoiceVibe ZIP

Already have an authorised WAV? Enter its name, description and exact recording transcript, choose the WAV, then save a ZIP with matching .md/.txt/.wav filenames. Processing happens locally; nothing uploads.

The ZIP contains only your three same-stem files. To add a new voice to the published library later, extract it into voice-vibes/ and add an entry to the external voices.json manifest. A static browser page cannot automatically write to GitHub.
