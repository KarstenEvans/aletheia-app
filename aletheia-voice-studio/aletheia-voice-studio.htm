Voice Studio 🎙️

Shape an original synthetic voice from words, or prepare two recordings of your own voice. Free-first, private-by-default, portable Markdown. No API key, account, or upload required for this prototype. Download 24 kHz mono WAV files for Qwen3-TTS.

Local draft, not a synthetic voice generator. This page can prepare descriptions and microphone recordings. Actual OpenAI voice creation happens separately through an approved account/API. Do not impersonate celebrities, actors, or other people, and do not upload their archival recordings.

What this can and cannot do

Creating a prompt-generated voice currently works for GPT-Live. OpenAI creates a saved voice ID without returning preview audio. Listen in a billed GPT-Live session or the official voice Playground. A browser's built-in speech reader is not a preview of the described synthetic voice.

2. Record your own voice

Read the on-screen text, use your microphone, listen locally, then download a 24 kHz, mono, 16-bit PCM WAV file ready to upload as a reference sample in Qwen3-TTS. Nothing leaves this browser page automatically. Conversion happens on your device after you stop recording.

Checking microphone availability…
You can record in a normal browser tab that allows microphone use. Some embedded file viewers prohibit it.

To record outside this viewer: Download and unzip the complete Voice Studio package. Open aletheia-voice-studio.htm directly in Chrome or Edge (not a preview pane), then select Allow when prompted. If local-file access is blocked by your browser, host it on HTTPS (such as GitHub Pages) or localhost. Audio remains in your browser until you choose Download.

3. Workflow, limits & evidence

From description

  • Edit an original adult voice description of at most 2,000 characters.
  • Copy the description into an authorised prompt-to-voice API client or Playground.
  • Use the saved voice ID with GPT-Live. Creation free; listening sessions billed.
  • Keep the description in portable Markdown.

From your own recording

  • Record exact consent and choose either The Raven or the rainbow reading as a 10–60-second sample. The two passages can also be recorded and downloaded separately.
  • Download and listen locally to both recordings as 24 kHz, mono, PCM WAV, which is compatible with Qwen3-TTS reference-audio upload.
  • For Qwen3-TTS, upload the WAV in Voice Clone (Base) ↗, with the corresponding spoken text in the Reference Text field (unless x-vector-only mode is selected). OpenAI requires separately approved access for recording-based voice creation.
  • Submit only through the permitted API workflow on a trusted server.
