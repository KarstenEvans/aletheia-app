Althea Beowulf

A Beowulf-inspired workshop for building a private AI studio from old phones, PCs and laptops. Plan distributed jobs, preview cheap layered animation, and export a portable work order.

What this version does: local planning and a real browser-drawn 2D animation. What it does not do: scan devices, run diffusion models, dispatch network jobs or turn phones into a shared GPU. Example node specifications are entered manually, not measured.

1. Your compute nodes

Start with the supplied example nodes or replace them with your actual hardware. No device information leaves this page.

RAM is not storage. A 256 GB phone may only have 6–8 GB physical RAM. Image AI support depends on the chipset and installed software.

2. Design a test clip

Use a static background and an animated robot. Divide frame ranges between available rendering devices.

Scheduling is a simple round-robin CPU-renderer demonstration, not a measured performance optimiser.

3. Amiga-inspired animation preview

A single background, colour-cycling lights and an independently moving AI-PI-style robot. All frames come from ordinary Canvas drawing, not generated AI images.

5. Engineering roadmap

  1. Now: browser planner and reproducible CPU-only animation example.
  2. Next: run frame ranges on two old computers, merge by frame number and compare speed.
  3. Then: secure localhost controller, optional phone worker via USB/Termux, benchmarks and throttling.
  4. Later: integrate compatible local diffusion/image engines and separate LLM adapters.
  5. Research: cross-device single-image model partitioning only if measured benefits justify the complexity.
