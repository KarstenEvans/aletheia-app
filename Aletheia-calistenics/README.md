## Chair Movement (review-only)

A free, source-linked seated mobility course preview is staged at [chair-exercises.htm](chair-exercises.htm). It uses [chair-workout.json](chair-workout.json) for the original course data and includes short narrated sessions, optional turning movements and clear stop guidance. It is not medical treatment, formal Tai Chi instruction or a replacement for strength training.
