[Aletheia Protocol](https://github.com/KarstenEvans/aletheia-protocol) — evidence, provenance, uncertainty and human control.  
[Thalia Protocol](https://github.com/KarstenEvans/thalia-protocol/blob/main/THALIA_PROTOCOL.md) — optional humour and positivity-first presentation.

Any Markdown generated by this app must retain both protocol references near the beginning.

## Purpose

A mobile-first, free-first Story Workout player. It turns a workout image into timed narrated scenes, zooms to the current movement, counts down, provides paced rests and rotates short healthy-ageing messages.

Capability level: **STATIC / LOCAL**. The ordinary workout runs in the browser. It does not require an AI account, paid API or cloud workout service.

## First workout

**Calisthenics with Cats** uses five ordinary autoplay movements:

1. Cat Stretch / Cat-Cow
2. Forearm Plank
3. Push-Up
4. Side-Lying Leg Circles
5. Glute Bridge

The poster's headstand remains an **advanced optional demonstration** and is deliberately excluded from normal autoplay. The app must not teach a beginner to perform a headstand.

## Story player behaviour

For each exercise:

- show the relevant crop/zoom from the master exercise artwork;
- introduce the movement and an easier modification;
- start the exercise timer;
- announce round ten-second markers;
- count the final ten seconds one by one;
- say “And rest”;
- start the configured rest period;
- select a rest message through a shuffle-bag with recent-repeat suppression;
- preview the next exercise;
- auto-advance unless the user disables that option.

Pause, previous, next and stop remain available during the workout.

## Voice

The app offers two logical trainer choices.

### Caroline — UK female

Prefer a good \`en-GB\` female voice when the device/browser exposes one. Because the Web Speech API does not provide reliable gender metadata, use sensible name hints and fall back to another \`en-GB\` voice.

### UK English Male — Storyteller rule

Reuse Aletheia Storyteller’s narrator preference order exactly:

1. \`en-GB\` + \`Google UK English Male\`, excluding \`George\`;
2. another \`en-GB\` voice whose name contains \`male\`, excluding \`George\`;
3. another \`en-GB\` voice, excluding \`George\`;
4. any \`en-GB\` voice;
5. another English voice.

**George is explicitly not a preferred voice.**

The menu should show the actual system voice selected on the current device so the user can tell what will be heard.

## Music

Reuse the proven Aletheia Frequency Explorer Web Audio pattern rather than the earlier near-silent custom oscillator mix.

Generated profiles:

- **Zen Garden 60 BPM** — Japanese contemplative-inspired pentatonic palette, soft drone, spacious generated phrases and a subtle one-second pulse;
- **Tao Flow 60 BPM** — Tao/Chinese contemplative-inspired palette, soft drone and one-second pulse;
- **Upbeat 120 BPM** — brighter generated phrases and a half-second pulse;
- **Local licensed track** — user-selected audio file that remains on the device;
- **Music off**.

Generated profile names describe mood/instrumentation inspiration, not authentic traditional performance.

Music starts only after the user explicitly starts a workout. Provide a visible music volume control and a visible failure/status message. Duck music while the trainer speaks, then restore it.

No commercial recording is bundled. The resource page may link to sources such as Pixabay for users who want to choose a suitably licensed local track; the licence of the exact track must be checked before redistribution.

## Burger/menu

Follow the established Storyteller interaction rather than a second bottom-navigation system:

- one \`☰ MENU\` control near the top right;
- \`aria-expanded\` and \`aria-controls\`;
- contained panel, not a full-page takeover;
- menu contains workout navigation, voice, speech rate, music, music volume, local audio chooser, captions, rest facts, auto-advance, install/help and resource links;
- Escape and outside click close the menu;
- workout state remains intact when the menu opens;
- external/resource links preserve workout state by opening separately where appropriate;
- no duplicate bottom navigation.

## Safety

The app is general fitness information, not diagnosis or treatment.

- Work within a comfortable range.
- Use an easier version when needed.
- If balance is uncertain, keep a wall or sturdy chair within reach.
- Stop for sharp/increasing pain, chest pain, severe dizziness/faintness, new numbness/marked weakness, or unsafe loss of balance.
- If the user has not exercised for some time, has a medical condition/injury, has frequent falls or is unsure whether an exercise is suitable, seek appropriate professional advice.

## Persistence and privacy

Only benign preferences such as voice mode, music mode, music volume, captions, rest facts, auto-advance and speech rate are stored in \`localStorage\`.

A user-selected local audio file is used only by the browser page and is not uploaded by the static app.
