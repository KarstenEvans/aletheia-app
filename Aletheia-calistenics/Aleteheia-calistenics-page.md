## Purpose

Let a visitor run a narrated bodyweight Story Workout directly in a phone or desktop browser. The app zooms the current exercise, times it, speaks calm cues and countdowns, provides rest periods and then advances.

The normal app is **STATIC / LOCAL** and requires no paid AI/API.

## Inputs and stored state

\`localStorage\` key: \`aletheiaCalSettings\`

Allowed benign preferences:

- logical voice mode (\`caroline\` or \`male\`);
- speech rate;
- music profile;
- music volume;
- captions;
- rest facts;
- auto-advance.

Local music file selection is not persisted and must not be uploaded.

## Data/parsing contract

\`workout.json\` supplies:

- workout title/safety text;
- exercise order;
- duration and rest seconds;
- crop rectangles;
- introduction/cue/modification/next text;
- rest fact pool.

Exercise assets use the embedded master poster in \`poster-data.js\` plus per-exercise normalized crop values.

Headstand may remain in advanced data/artwork but is excluded from default autoplay.

## Required controls and exact behaviour

### Header/menu

- visible \`☰ MENU\` button
- \`aria-expanded\`
- \`aria-controls="menu"\`
- menu opens without changing workout state
- closes via button, Escape or outside click
- menu includes Home, Workout overview, Voice, Speech rate, Music, Music volume, optional local audio, Captions, Rest facts, Auto advance, Install, Resources, Books & Gifts and Apps home

### Voice

Logical choices:

- \`Caroline — UK female\`
- \`UK English Male — Storyteller\`

Male resolution order must match Storyteller:

1. Google UK English Male + en-GB + not George
2. another en-GB male + not George
3. another en-GB + not George
4. any en-GB
5. another English voice

Show actual resolved device voice. Do not silently choose George as the preferred male narrator.

### Music

Generated music starts only from an explicit Start/Resume user gesture.

Profiles:

- Zen Garden 60 BPM
- Tao Flow 60 BPM
- Upbeat 120 BPM
- Local licensed track
- Off

Port the Frequency Explorer pattern:

- AudioContext
- music master gain
- reverb convolution
- drones
- scale-based generated phrases
- audible default master level near the earlier Frequency Explorer \`0.09\`
- gentle BPM pulse
- music ducking during narration
- visible audio status/failure state

Music volume must be adjustable from the menu.

### Player

- exercise title and sequence
- zoomed exercise image
- remaining timer
- caption/cue
- modification text
- Previous
- Pause/Resume
- Next
- Stop

Countdown pattern:

- round ten-second announcements;
- final ten seconds spoken every second;
- countdown speech is quieter than ordinary coaching until the last few seconds.

### Rest

- visible rest timer
- one shuffle-bag fact with recent-repeat suppression
- next-exercise preview
- Pause/Resume, Next and Stop
- optional auto-advance

## Navigation/window behaviour

Internal workout routes remain in the current page.

Resource and Books & Gifts links open separately while a workout may have state worth preserving.

Editorial/source links use ordinary HTTPS and \`data-awinignore\` where appropriate.

## Browser/device capability matrix

Baseline:

- static workout cards and text remain understandable without speech/music
- current Chrome/Edge desktop target
- Android Chrome target
- Safari/WebKit target where APIs exist

Enhancements:

- Web Speech API for narration
- Web Audio API for generated music
- PWA install prompt where supported

Fallbacks:

- missing speech: timers/captions still work and a visible menu/status note explains narration is unavailable
- missing Web Audio: workout still works and visible audio status says music could not start
- PWA install prompt unavailable: show platform-appropriate Add to Home Screen guidance

Do not claim device compatibility until actually tested.

- safety text remains visible

## AI/agent authority

Normal page requires no AI authority.

Repository maintenance uses the normal Aletheia READ → DRAFT/LOCAL → EXTERNAL/PUBLISH ladder. GitHub publication is separate from local generation and must be recorded honestly.

## Persistence/resume behaviour

Preferences survive page reload through localStorage.

The workout does not currently persist mid-exercise progress. Reload returns to Home. This is acceptable for MVP and must not be described as resumable workout state.

## Security/privacy

- no secrets or API keys
- no hidden upload
- local selected audio remains local
- external links do not receive private workout state
- dynamic visible text uses trusted local JSON; do not introduce untrusted HTML injection
