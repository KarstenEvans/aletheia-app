Three easy steps

  1. Download the ZIP that matches your AI.
  2. Import it using your AI's Skill or plugin controls, where supported. If your AI cannot import Skills, use the ordinary Trust Check Markdown instead.
  3. Ask normally: “Can I trust this company?” or “Check the claims in this post.”

The Skill does not give an AI web access or permission to act. It must say when information could not be checked. A missing search result is not proof that something is false.

Need platform-specific instructions?

Claude and Gemini

Use your AI's custom Skill import feature if your account supports it. Upload the Skill ZIP, which contains the instruction file and reference material. Availability and menu labels depend on your account.

Microsoft Copilot

In an eligible Copilot Studio agent, add an existing Skill and upload the Skill ZIP. Microsoft 365 Copilot Agent Builder preview also accepts a ZIP. This is not automatically available in ordinary free Copilot chat.

ChatGPT and Codex

Use the Plugin ZIP with a supported local/personal plugin marketplace or plugin-creation workflow. A public listing requires separate submission and approval.

DeepSeek, Odysseus and other AI tools

If your particular AI environment supports SKILL.md imports, use the Skill ZIP or extract its files. Otherwise open the original Trust Check Markdown in the AI. Ordinary chat and developer agent environments are not necessarily the same product.
