    How this works

    The launcher refreshes its small repository registry, queries current GitHub trees, looks for the named project and related files, then assembles a provider-neutral prompt. It does not replace the project’s own Markdown, GUI rules or development guide.

    Existing first: if another Aletheia app, Skill or knowledge collection already covers the job, Improve asks the AI to extend, link or consolidate before creating anything new.
