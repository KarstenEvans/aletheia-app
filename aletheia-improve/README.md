# Aletheia Improve

Aletheia Improve is the maintenance and improvement launcher for the Aletheia family of apps, knowledge collections, stories and related Swindon.org.uk pages.

## Files

- \`aletheia-improve.md\` — canonical AI workflow and improvement contract.
- \`aletheia-improve-memory.md\` — repository/path registry read on each run.
- \`aletheia-improve-page.md\` — browser-page build and QA specification.
- \`aletheia-improve.htm\` — runnable static launcher.
- \`aletheia-improve-rsc.htm\` — supporting free resources and clearly separated commercial possibilities.
- \`tasks.md\` — implementation/testing work.
- \`ideas.md\` — future ideas that are not requirements for v1.

## Public app

https://karstenevans.github.io/aletheia-app/aletheia-improve/aletheia-improve.htm

## Principle

Refresh current repository state first. Find what already exists. Improve the smallest thing that materially improves usefulness. Do not rebuild a working app from chat memory, and do not create a near-duplicate merely because a new name was spoken.

The browser launcher is deliberately static/free-first. It can fetch public GitHub source, accept local supporting files, assemble a current improvement pack and hand that pack to a user-selected AI. It does not pretend that one website can silently upload files into another AI provider.
